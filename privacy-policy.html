Privacy Policy

Effective: May 2, 2026

1. Data Collection

PullNova collects only the minimum data required to operate: repository metadata, pull request diffs for analysis, and basic account information (email, username). We do not collect browsing behavior or sell any data.

2. Code Processing

Source code is processed in-memory during analysis and never persisted to disk. Analysis results are retained for 30 days (configurable for Enterprise). We never train AI models on customer code.

3. On-Premise Option

Enterprise customers can deploy PullNova entirely within their own infrastructure. No code leaves your network.

4. Security

TLS 1.3 encryption, SOC 2 compliant infrastructure, regular penetration testing, and strict access controls.

5. Contact

Questions? Reach out at hello@pullnova.net.
